# AI Voice Assistant - Frontend

This directory houses the React.js web client for the **AI Voice Assistant** multi-business SaaS platform.

## Technology Stack

- **Framework**: React 18 / 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **HTTP Client**: Axios

## Planned Modules

1. **Multi-tenant Business Portal**:
   - Organization registration and settings.
   - Business hours, services, and FAQ management (for hospital, hotel, salon, auto service, real estate verticals).
2. **AI Voice Agent Customizer**:
   - Greeting scripts, tone, prompt overrides, and fallback escalation rules.
3. **Live Receptionist & Call Analytics Dashboard**:
   - Real-time call logs, duration, caller intent classification, sentiment.
   - Audio recording playback and full conversation transcriptions.
4. **Appointments & Bookings**:
   - Integrated calendar view with status indicators (confirmed, cancelled, rescheduled).

## Setup & Development (When Commencing Frontend Phase)

```bash
# Navigate to frontend folder
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```
